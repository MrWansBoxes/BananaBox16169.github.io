# Banana Box — FTC Team 16169

**Banana Box** is a community FIRST Tech Challenge team based in Windham, NH. We design, build, and program competitive robots, and we work to bring FIRST to as many people as possible — from mentoring rookie teams to running events that have reached over 21,000 people.

Our website is live at [www.ftcbananabox.com](https://www.ftcbananabox.com).
